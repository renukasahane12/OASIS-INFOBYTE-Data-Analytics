# OASIS INFOBYTE – Data Analytics Internship

This repository contains the tasks completed during my Data Analytics Internship at OASIS INFOBYTE.

## About the Internship

The internship focused on applying data analytics and machine learning techniques to real-world datasets. The tasks covered data cleaning, exploratory data analysis, visualization, NLP, predictive modeling, classification, and other practical analytics applications.

## Tasks Completed

### Level 1

1. **EDA – Retail Sales**
   - Exploratory Data Analysis
   - Sales trends and customer behavior
   - Statistical analysis and visualizations

2. **Customer Segmentation**
   - Customer segmentation using K-Means clustering
   - RFM-based customer analysis
   - Cluster visualization and insights

3. **Data Cleaning**
   - Missing value treatment
   - Duplicate removal
   - Outlier detection
   - Data type and format correction

4. **Sentiment Analysis**
   - Text preprocessing
   - TF-IDF feature extraction
   - Machine learning-based sentiment classification
   - Model evaluation

### Level 2

1. **House Price Prediction**
   - Exploratory Data Analysis
   - Feature preprocessing
   - Linear Regression
   - Model evaluation

2. **Wine Quality Prediction**
   - Data preprocessing
   - Feature scaling
   - Classification models
   - Model comparison and feature importance

3. **Fraud Detection**
   - Class imbalance handling
   - Logistic Regression
   - Random Forest
   - Fraud detection model evaluation

4. **Google Play Store Analysis**
   - Data cleaning
   - App category analysis
   - Rating, reviews and installs analysis
   - Free vs paid app analysis

5. **Autocomplete & Autocorrect**
   - NLP preprocessing
   - Word frequency analysis
   - Bigram and trigram models
   - Autocomplete
   - Edit-distance based autocorrect
